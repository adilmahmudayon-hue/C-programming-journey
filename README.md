## ▶️ How to Compile and Run

Most programs in this repository are standalone C programs.

### Using GCC

Compile a program with:

```bash
gcc program.c -o program
```

Run it on Windows:

```bash
program.exe
```

On Linux/macOS:

```bash
./program
```

For example:

```bash
gcc hello.c -o hello
```

Then:

```bash
hello.exe
```
